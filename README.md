# PM2.5 Explorer

โครงการวิเคราะห์และสำรวจข้อมูลฝุ่นละออง PM2.5 เพื่อศึกษาสถานการณ์คุณภาพอากาศและค้นหารูปแบบของข้อมูลผ่านกระบวนการ Exploratory Data Analysis (EDA)

## Objectives
- ศึกษาและสำรวจข้อมูล PM2.5
- ฝึกทำความสะอาดและจัดการข้อมูล
- วิเคราะห์ข้อมูลด้วย Python และเครื่องมือ Data Science
- นำเสนอผลการวิเคราะห์ข้อมูล

## Tools & Technologies
- Python 3.12
- uv
- Jupyter Notebook
- Pandas
- DuckDB
- Streamlit


